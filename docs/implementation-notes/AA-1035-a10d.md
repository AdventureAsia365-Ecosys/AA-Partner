# AA-1035 A10d (S270, lane aa1035-a10d-cs-e2e-identity) — AA-Partner half

Root ADR 0006a A10d: a Dev-only WORKFORCE E2E identity `e2e-cis-cs@e2e-mail.lumiguides.it.com` with exactly
`cis-customer_success`, read-only in CIS with no write allow-list. CIS half: AA-CIS-App
`docs/implementation-notes/AA-1035-a10d.md`; Infra half: AA-CIS-Infra `docs/implementation-notes/AA-1035-a10d.md`.

## Decisions
- A separate `Caller.e2e_no_write` flag, set by the route guard for a WORKFORCE token whose `email` claim is the A10d
  address. **Not** `Caller.e2e_read_only`: in `studio_invitation` (`api/app/routers/ops.py`), `e2e_read_only` plus an
  address runs `studio.check_e2e_invitation`, the A10b-1 path, so the cs identity could invite E2E-mailbox addresses on
  synthetic tenants (critic correction recorded in the S270 scope).
- `studio_invitation` refuses `e2e_no_write` with 403 `e2e_read_only` as its first statement, before the CIS
  staff-scope read, with or without an address. It is the only `/crm/ops/v1` write a `cis-customer_success` token
  reaches; every other ops write is `PlatformAdmin` (`require_group(crm-platform-admin)`), which now refuses the flag too
  (second lock: the trigger never issues the cs address `crm-platform-admin`).
- Like A10c, the guard refuses the identity outside `dev` / `test` / `local` (403 `e2e_read_only`): the token cannot
  exist elsewhere, this is the second lock.
- `/console` answers `can_write: false` for it; `is_e2e_mailbox_address` never treats the A10d address as an invitee.

## Changed
- `api/app/auth/e2e_staff.py` (`E2E_CIS_CS_EMAIL`, `is_e2e_cis_cs`), `api/app/auth/route_guard.py` (`e2e_no_write`,
  environment lock, `require_group`), `api/app/routers/ops.py` (`studio_invitation`, `/console`), `CONTEXT.md`.
- Tests: `api/tests/unit/test_aa1035_a10d_e2e_cs.py`.

## Tradeoffs
- A separate flag rather than widening `e2e_read_only` keeps the A10b-1 exception exactly as reviewed.

## Should know

- `test_ops_staff_scope.py` (a real `cis-customer_success` caller gets 202 on the relay) stays green.
