# AA-1062: studio legal pages Draft v0.6 (no "last resort" writer)

## Decisions

- The provider sentence follows the AI Use Register v1.13 (root `docs/architecture/ai-use-register.md`, "Providers,
  for the tenant terms") and root `docs/generated/llm-routes.md` (snapshot 2026-11-09): since CIS migration 383 (route
  control version 7, 2026-11-06) every writer route is Claude only (`sonnet-5-5` / `haiku-5-5` and their 4.x rungs,
  the Anthropic API first, Amazon Bedrock second). The OpenAI API stays on the judge / validate routes only.
- The removed sentence ("If no Claude model is available, an OpenAI model through the OpenAI API may write it as a last
  resort.") is replaced, not just deleted: "Only Claude models write it: if no Claude model is available, the writing
  step waits and is tried again later." This is what the gateway does (register v1.13: a writer whose Claude rungs all
  fail stops with `queue_retry`). Vietnamese: "Chỉ các mô hình Claude viết nội dung: nếu không có mô hình Claude nào
  khả dụng, bước viết sẽ chờ và được thử lại sau."
- The rest of §3 / §5 is unchanged: OpenAI models still review, score and check (through Amazon Bedrock or the OpenAI
  API), Amazon Nova / Meta Llama may still review and check, both direct APIs are still named as providers that may
  process the content.
- Version frame: Draft v0.6, last updated 10 November 2026 (EN) / Bản nháp v0.6, 10 tháng 11 năm 2026 (VI).

## Changed

- `web/app/(studio)/legal/partner-terms/terms.messages.ts` §3 and `web/app/(studio)/legal/privacy/privacy.messages.ts`
  §5, EN and VI; `web/app/(studio)/_legal/legal.messages.ts` version and date.

  both languages, (1) no stale writer phrase ("last resort", "may write it", the Draft v0.5 Vietnamese wording), (2)

  Claude, (3) the frame shows v0.6. A self-test proves the guard flags the Draft v0.5 sentence.

  required writing phrase is "Only Claude models write"; the frame version is v0.6.

## Tradeoffs

- The Partner repo cannot read the root register in CI (separate repo), so the writer provider list is a constant in
  the guard with a pointer to the register. A register change that adds a writer provider must update that constant
  in the same change as the page copy; the guard comment says so.
- Sentence-level matching is a heuristic: a sentence that both says who writes and names a reviewer would fail. The
  pages keep writing and checking in separate sentences, which also reads more clearly.
