# AA-1027 F4 (interim path): the draft route on Amazon Nova Lite (acc2)

Lane l5-crm-f4-path of S266. S263 gateway plan row F4, re-scoped by the tech lead in S265 (AA-1027 comment): one real
CRM draft on a cheap acc2 model through the gateway (~0.001 USD), ledger row priced from the catalogue; the acc3
Haiku draft is a follow-up check for when acc3 answers again. Companion PRs: AA-CIS-Infra `crm_llm.tf` (task env +
`bedrock:InvokeModel` on that profile), root ADR 0009 decision 14 amendment.

## Decisions

- **Why a migration at all.** The gateway plays the stage's route entries, not `CRM_LLM_MODEL_ID`: the crm-037 route
  is Claude Haiku then Sonnet, which acc2 cannot run (and acc3 refuses every model). Switching the provider without
  a route change gives two refused AccessDenied rows and a "reply by hand" draft.
- **Model: Amazon Nova Lite** `us.amazon.nova-lite-v1:0`, family `amazon`, 0.0770 / 0.3080 USD per million tokens,
  equal to the CIS catalogue row `nova-lite` (CIS migration 324): the cheapest acc2 chat model CIS prices and probed.
- **Keep the Claude rows, switched off** (`is_enabled = false`), and add Nova Lite at position 2. The acc3 return is
  then one forward file that switches 0 and 1 back on (route Haiku, Sonnet, Nova Lite; `max_attempts` 2).
- **No code change.** `build_gateway()` already builds the Bedrock provider from `CRM_LLM_*`; the route's catalog
  prices reach `pricing.quote`. The Infra env sets the same prices as the route, so the cost equals the catalogue
  price (`pricing_mode` reads `override` because the env price wins for the configured model; same numbers).
- **Contract, MIG-4, no readiness raise.** Configuration rows in an existing table (UPDATE + INSERT) are contract;
  nothing in the code reads crm-042 by key, and the code works with either route.

## Tradeoffs

- A writer stage on acc2 against root ADR 0009 decision 14 ("writers stay on Claude"): the tech lead's S265 re-scope;

- One entry, no second acc2 model behind it: a failed call is "reply by hand"; a fallback would double the paid
  attempts of a path test.
