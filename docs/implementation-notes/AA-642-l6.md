# AA-642 L6 — CI guard against model calls that bypass the gateway (AA-Partner part, slice G2)

Plan: root `docs/audits/2026-11-01-S263-gateway-gap-audit/plan.md` §1.G (G2). Same rule as AA-CIS-App
`tests/unit/test_aa685_no_raw_model_calls.py` and AA-TripPlanner-Web `backend/tests/test_no_gateway_bypass.py`.

## Decisions

- **One unit test, `api/tests/unit/test_gateway_bypass.py`,** in the "Unit Tests" job. Python under `api/app` and
  `api/scripts` is parsed with `ast`; docstrings and comments do not count.
- **Patterns:** Bedrock `invoke_model*`, `converse*`, `apply_guardrail`, `create_model_invocation_job` as attributes
  (a call or a method passed uncalled: the Bedrock provider runs `asyncio.to_thread(client.converse, ...)` and the
  guardrail `asyncio.to_thread(self._client.apply_guardrail, ...)`, which a call-only check would miss); vendor SDK
  `.completions|.messages|.responses|.embeddings` `.create|.stream|.parse`; importing `openai` / `anthropic`; vendor
  endpoint strings `api.anthropic.com`, `api.openai.com`, `bedrock-runtime`.
- **ALLOWED = the gateway's two provider modules,** each with a reason: `app/llm/providers/bedrock.py` (Converse
  after scrub, budget and `ai_enabled`) and `app/privacy/guardrails.py` (the scrub's pass 3, ledgered as guard rows).
  Ratchet: an entry with no hit left fails.
- **Frontends:** a line regex over `web/` and `portal/` sources rejects `openai`, `@anthropic-ai/*`,
  `@aws-sdk/client-bedrock*`, `@ai-sdk/*` imports and vendor endpoints.
- `app/aa_llm/` (vendored core) is scanned, not exempt: it holds no call.

## Changed

- Nothing in runtime code. The scan found no bypass outside the two providers.

## Tradeoffs

- The test executes no `app` module, so the coverage TOTAL does not move (coverage measures `app` only).

## Should know

- Verified locally: a planted `rt.converse(...)` in `app/` fails the test with file and line.
- Lane L5 (CRM gateway F1/F2) edits `app/llm/*` in parallel. A new provider module there must be added to ALLOWED
  with its reason in the same PR, or this test fails.
