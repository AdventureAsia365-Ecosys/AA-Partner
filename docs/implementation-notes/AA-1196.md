- **Red run -> one issue.** A separate `report` job (`issues: write` only) opens "E2E Dev (CRM) is red" with label
  `e2e-dev-red`, comments while red, closes on green: the CIS nightly-integration pattern. The test job keeps

- No product change: every CRM failure was the spec lagging behind an intended product rule.
