# AA-1168 follow-up — the export disclosure reads the CIS setting (AA-Partner)

Lane l11-ai-disclosure-setting, S286 (settings-rule audit). The My Content CSV / XLSX export (`AA-1168.md`) ended with
a hand copy of the CIS disclosure constant ("keep in sync by hand"). The wording is now the CIS setting
`cis.content.ai_disclosure` (CIS 463, Platform › Settings, editable by an administrator, audited), so this repo reads it
instead of copying it.

## Decisions

- **Read path:** CIS `GET /v1/content-writing/ai-disclosure` (tenant token) through the existing tenant BFF proxy
  `/api/tenant/[...path]` (no allow-list change: the proxy forwards any `/v1` path with the verified studio token).
  `catalogApi.fetchAiDisclosure()` reads it at export time, next to the version detail reads; a failure returns null
  and never blocks an export.
- **Which line:** `exportDisclosure(cfg, versions)`: the line of the versions' language when every selected version
  shares one (`rewrite_language`, `vi-VN` → `vi`), else English; English when the setting has no line for that
  language. The response always has an English line (CIS refuses a value without one).
- **Fallback only:** `AI_DISCLOSURE_TEXT` stays as the English seed, used when the read fails or the response has no
  usable English line, and when a line comes back blank. The file never ends with an empty line: the disclosure cannot
  be switched off, only reworded in CIS.

## Changed

- `web/lib/studio/catalogExport.ts`: `AiDisclosure` type, `exportDisclosure`, `catalogTsv(rows, disclosure)` and
  `catalogWorkbook(rows, disclosure)` (the default argument is the fallback line, so other callers keep working).
- `web/app/(studio)/portal/_components/catalogApi.ts`: `fetchAiDisclosure`.
- `web/app/(studio)/portal/_components/CatalogTab.tsx`: `exportSelected` reads the wording with the details.
- `web/tests/studio/catalogExport.test.ts`: the read value, the language pick, the fallbacks, the CSV / XLSX trailer.

## Tradeoffs

- One extra GET per export click (no caching): the export is rare and the wording should be the one in force now.
- Mixed-language selections get the English line rather than one line per language: one trailer line keeps the file
  shape of AA-1168 (scripts reading the table see one short last row).
