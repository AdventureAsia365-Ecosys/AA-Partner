# AA-1087 (S278 lane l18) — AA-Partner: the CRM half of the crm-13 E2E check

The Dev-only E2E write identities of AA-Booking (root ADR 0006a A10e, A10e-1) can cancel a departure the fixture
seeder made for synthetic agencies. The review of the lane found that nothing showed the agency CRM opening its
`crm.aa_cancel_case` in the same run: the seeder's booking is a staff desk booking, which creates no CRM trip, so the
CRM had nothing on the departure for its feed to flag.

## Decisions

- **A CRM trip of its own on the seeded departure.** `e2e/tests/aa-cancel.spec.ts`, phase `prepare`, signs in as the
  CRM E2E owner, makes a trip through the inquiry form, starts the builder and adds the seeded tour as an AA item ON
  the seeded departure (live Booking quote) in a draft version: the CRM's `AFFECTED_SQL` matches a live builder
  version's AA option on the departure. No CRM code or data shortcut.
- **Two phases, one input.** Both phases read the AA-Booking seeder's APPLY output (departure id and start, tour
  source id and component, `agency.crm_e2e`); `prepare` writes the trip id to a state file that `verify` reads. The
  seeder targets the CRM E2E agency by default; the spec refuses an output made for another agency.
- **Agent-only.** Like the Booking e2e-writers project: `e2e-dev.yml` sets no `E2ECRMAACANCEL`, so both tests skip
  there and the workflow is unchanged. The run needs the orchestrator's order (seeder -> prepare -> Booking cancel ->
  verify).

## Changed

- `e2e/tests/aa-cancel.spec.ts`, `e2e/helpers/aaCancel.ts` (pure helpers), `e2e/unit/aa-cancel-helpers.spec.ts`,
  CONTEXT.md (crm-13 section). No API, web or migration change.

## Tradeoffs

- The trip and its case stay on the Dev board as the run's evidence (named "E2E <run> AA cancel"); a later run makes a
  new one. Cleaning up would need the cancel flow (b), which is a different check.
- `verify` polls up to 5 minutes: the CRM pulls the Booking feed in its minute job.

## Should know

- Live order: AA-Booking seeder `--apply` (save the JSON) -> `E2ECRMAACANCEL=prepare` -> AA-Booking
  `e2e-writers` (cancel, `BOOKING_E2E_FIXTURES` = the same file) -> `E2ECRMAACANCEL=verify`.
