# AA-1088 — Pre-pilot quick fixes (AA-Partner part: M3 studio side, M6, M9)

Three items of the S278 system audit that a pilot agency would meet in the Content studio. The CIS part of M3 (the
409 and the audited override) ships in AA-CIS-App first; AA-Booking has M13.

## Decisions

- **M6 drawer**: the whole "Where this came from" block is gone from `ReviewDrawer.tsx` (goal, tour, angle with its
  formula and style, source fact, search context, CTA). The issue asks for "only the agency's own text and the AA
  notice"; the goal and tour rows were harmless but sat in the same block, and the row title and list already show the
  topic. The API still returns those fields: the Create wizard (`AngleGateWizard.tsx`) shows the angle cards the agency
  picks from, which is the agency's own step.
- **M3 studio**: the reason is the studio's own EN / VI sentence keyed on the refusal code, not CIS's English
  sentence (CIS's sentence still shows in an old studio build, because it is the body's string `detail`). The code is
  read from the body (`code`), since the tenant BFF forwards only the content type (and the download headers).
- **Publish anyway** appears only on the Publish page card, only after the refusal and only when CIS says
  `can_publish_anyway` (the account owner). My Content bulk publish and the Writer panel show the reason; the owner
  sentence points to the Publish page.
- **M9 legal**: partner terms §2 now describes the partner sign-in (each person's own sign-in with a second step, the
  owner sets roles and removes access, report a leaked sign-in). The other API-key mentions went with it: the intro
  ("and its API"), §3 ("through the API" twice) and §5 ("API access"). Privacy §2 "Partner account" lists e-mail,
  role and sign-in, held by the sign-in service on Amazon Web Services. Draft version v0.6 -> v0.7 (12 November 2026).

## Changed

- No new API route and no BFF change: the override is a JSON body on the existing publish POST.

## Tradeoffs

- The legal text stays a draft for the business owner and counsel; only facts about sign-in changed, nothing about
  liability or fees. The cookie paragraph ("expire after 24 hours") was not touched.
