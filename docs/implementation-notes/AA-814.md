# AA-814 — Content studio: Brand › Facts (S257)

The tenant half of the Facts Entry work. The API, the precedence rule and the admin page are in AA-CIS-App
(`api/routers/v1_facts.py`, `services/acp_shared/facts_store.py`, `services/acp_content_writing/facts.py`, CIS
migration 302); its implementation notes hold the backend decisions. This repo only adds the studio page.

## Decisions

- **Page** `/portal/facts`, nav group Brand, entry "Facts" (beside Brand Identity: the facts are the agency's own
  material for the writer, like its brand rules). Not under `/portal/brand/…`: `navActive` would light Brand Identity
  for it too.
- **Two tables:** "Your facts" (own facts, expired ones flagged; a row opens the edit drawer with Delete) and
  "Adventure Asia facts" (valid platform facts, read only). On a platform fact, "Use my own" opens the add dialog
  with the same kind, subject and country (the writer's subject key), so the override needs no typing of the key;
  a platform fact that already has an own version shows "Replaced by yours" and opens that fact.
- **Duplicate subject warning:** adding or editing an own fact whose subject matches another own fact shows a note
  (the writer keeps the newest stated one). Not blocked: the API allows it.
- **Roles:** the page does not read the studio role. A viewer sees the same page; every write answers 403 from CIS
  (tenant_role middleware) and the page says "Your role can read facts but not change them". Same as the other
  studio pages, which do not hide controls per role either.
- **Edits** send only the changed fields plus `expected_updated_at`; a 409 asks to reopen. Limits mirror the CIS ones
  (title 200, fact 1200, source 500, country 80; 200 own facts, the add button is disabled at the limit).
- **English only:** the portal has no UI-language switch yet; text is plain English like its other pages.
- **Kit:** PageHeader, DataTable, Drawer, Modal, ConfirmModal, Button, Badge, tokens (`K`, `RADIUS`, `sans`); no import
  of the legacy `_components/ui.tsx`. Pure rules in `lib/facts.ts` (no React), tested by `lib/facts.test.ts`.

## Changed

- Nothing in the BFF: `/api/tenant/[...path]` already forwards `/v1/facts` with the verified studio token and refuses
  cross-site writes.

## Tradeoffs

- Country is free text (the writer compares it case-insensitively with the piece's destination) rather than a picker:
  the CIS destinations use plain country names and a picker would need a new list endpoint.
